# API Connect

## Descrição do Projeto
A API Connect é um Produto Mínimo Viável (MVP) desenvolvido para gerenciar o cadastro e a manipulação de dados de usuários. A aplicação segue os princípios da arquitetura RESTful, provendo uma interface limpa, escalável e padronizada para integração com front-ends ou serviços externos através do protocolo HTTP e payloads no formato JSON.

---

## Tecnologias Utilizadas
* Linguagem: Python
* Framework Web: Flask
* Formato de Dados: JSON
* Controle de Versão: Git / GitHub
